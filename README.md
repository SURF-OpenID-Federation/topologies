# Federation topologies

This repo contains the results of an attempt to, in a reproducible way, design and evaluate federation topologies based on the use of OpenID Federation.

To perform the evaluation, open source (GTP-oss-120b) and commercial IA models (CHATGTP) were used which were provided with the OpenID Federation 1.0 and OpenID Federation for Wallet Architectures 1.0  specifications as conext..

The federation models were all described using the mermaid language, whereas the evaluation matrix is described in markdown.

Purpose of this approach was to:
1) Test the ability to easily model and evaluate and compare federation topologies for similar scenarios.
2) Work with the AI LLMs to readily generate evaluations on  either general or rather very specific aspects of the topology with respect to certain aspects of the OpenID federation specification. 
3) Modify and change aspects of the topology and readily re-evaluate topology models against existing matrix and existing topology models.

The currently included scenarios explores various federation models we (may) have in Research and Education, including:
* National OIDC based OpenID Federation – 3 scenarios
* eduGAIN OIDC based inter-federation – 2 scenarios
* Hybrid federation (OIDC & Wallets) – 4 scenarios

The models, evaluation matrix and the evaluation results are all include and may be used for further analysis or re-evaluation.

DO NOTE! The evaluations are generated by AI and these may(/will) contain errors. Do not take the evaluations as is!
